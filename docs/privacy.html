Privacy Policy

Internet Ranked Bot · Last updated November 2, 2026

The Internet Ranked Bot ("the app") is a personal automation tool run by the owner of the Internet Ranked YouTube channel. It is used only with the owner's own Google account. It is not offered to the public, and no one else signs in to it.

What the app accesses

When the owner signs in, the app asks Google for permission to:

  • YouTube: upload videos and thumbnails to the owner's channel, list the channel's own videos, and read the channel's own analytics (views, watch time, likes, subscribers gained).
  • Google Drive: read video clips from the owner's "Internet Ranked Inbox" folder and save finished videos to the owner's "Internet Ranked Done" folder.

How the data is used

  • Clips are used only to build the channel's daily Short and are uploaded only to the owner's own channel.
  • Channel statistics are used only to produce a weekly performance report for the owner.
  • The app does not sell, rent, share, or transfer Google user data to anyone, and does not use it for advertising.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

The sign-in token is stored as an encrypted secret in the owner's GitHub account and is used only by the app's scheduled jobs. Video files are processed temporarily and kept in the owner's own Google Drive. The app keeps no other copies.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops the app immediately.

Contact

Questions about this policy can be sent through the Internet Ranked YouTube channel or by opening an issue on the app's GitHub repository.
